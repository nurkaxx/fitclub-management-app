# FitClub Management App

FitClub Management App is an information system for managing fitness club activities. It helps clients register, purchase memberships and book workouts.

## Purpose

To automate fitness club operations and simplify client and workout management.

## Users

- Client
- Trainer
- Manager
- Payment System

## Requirements

1. A client can register and log in.
2. A client can view available memberships.
3. A client can purchase a membership.
4. A client can make online payments.
5. A client can book a workout.
6. A trainer can view the workout schedule.
7. A trainer can conduct workouts.
8. A manager can manage clients, trainers and memberships.
